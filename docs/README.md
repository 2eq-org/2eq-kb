# Source Documents

## Purpose of this section
This section archives the **primary source materials** associated with the 2EQ framework and the Singular Motivational Subversion Hypothesis (SMSH).

These documents provide background, context, and original exposition.  
They are included for **transparency and reference**, not as proof of any claim.

Where possible, key concepts are summarized in HTML elsewhere in this knowledge base to improve accessibility and evaluability.
